# Ganesh Holkar — Freelance Portfolio

A responsive lead-generation portfolio for freelance web development and technical delivery services.

## Included
- Dark, responsive Next.js website
- Services for web applications, CMS/e-commerce, integrations and technical delivery
- Selected project experience and technology stack
- Contact enquiry form API using Resend
- Mobile navigation and animated interactions

## Run locally
```bash
npm install
npm run dev
```
Visit http://localhost:3000.

## Contact form setup
Configure `RESEND_API_KEY`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL`, and `NEXT_PUBLIC_SITE_URL` in your environment. The sending domain must be verified in Resend. Without configuration, the form returns a setup message instead of claiming the enquiry was delivered.

## Deploy to Vercel
Import this repository into Vercel, select the Next.js preset, configure the contact-form environment variables, and deploy. Add your existing domain in Vercel project settings when ready.

## Accuracy
The portfolio uses professional experience and skills supplied by the user. It does not invent client results, performance metrics, testimonials, pricing, guarantees or availability.
